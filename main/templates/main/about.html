Hello BoardGame Geeks.

I wanted to know what I should buy next... What would I like? So, this is an analysis site of BGG to calculate recommendations of what to buy next.

Games are scraped for their ratings. This takes long and only the top few games on the ranking is currently known.

The ratings were used to build a recommender system using SVD. Recommendations are calculated based of each players' ratings .

Look up your username and there should be recommendations on the user's page. It is updated about every {{ player_turnover }} days and should change if ratings were added/changed to the list of games.

More games will be added but it takes a long time. About {{ game_added }} games are added every day.
