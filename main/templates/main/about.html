Hello BoardGame Geeks.

I wanted to know what I should buy next... What would I like? So, this is an analysis site of BGG to calculate recommendations of what to buy next.

Games are scraped for their ratings. This takes long and only the top few games on the ranking is currently known.

The ratings were used to build a recommender system using SVD. Recommendations are calculated based of each players' ratings. Only the ratings of players are used that have minimum {{ min_used }} to maximum {{ max_used }} ratings. Ironically the OGs with thousands of ratings does not help anyone else to realise what they would like.

Look up your username and there should be recommendations on the user's page. Click the Recalculate and wait a few minutes to update your recommendations. (Otherwise it is stale - the oldest updated recommendations is {{ player_turnover }} days.

More games will be added, but it takes a long time as the sqlite db is bound to start getting slower performance. About {{ total_games }} games are added over a year
