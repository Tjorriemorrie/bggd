Hello BoardGame Geeks.

This is an analysis site of BGG.

Games are scraped for their ratings. This takes long and only the top few games on the ranking is currently known.

The ratings were used to build a recommender system. Based of each players' ratings recommendations are calculated.

Look up your username and there should be recommendations on the user's page. It is updated weekly and should change if new ratings were made or changed to the list of games.

More games will be added but it takes a long time.
